# GuiCreator | The Ultimate In-Game Gui Builder

![GuiCreator | Plugin by Hoogkids!](https://cdn.modrinth.com/data/cached_images/f3034737defd965381ce6efc86253a91aa4ebd68.png)

GuiCreator makes designing user interfaces effortless. No coding is required to build a gui, customize, and manage your menus directly inside an in game gui.

## Key Features

* **In-Gui Editor:** Create and edit complex GUIs directly inside a gui.
* **Item Management:** Add, rearange, and customize items with a few clicks.
* **Dynamic Actions:** Assign commands or functions to specific items easily.
* **Fast Workflow:** Built to save developers and administrators hours of manual configuration time.
* **YML Configuration:** Simple and structured GUI creation via YML files.
* **Versatile Layouts:** Create GUIs in all shapes and sizes.
* **Multiple Inputs:** Includes chat input support and more.
* **Permission Support:** Control access to your menus with custom permissions.
* **Multiple GUI Types:** Easily create and manage many gui types, including enchanting tables, beacons, and custom dialogue menus.
* **Automatic Page Generation:** Automatically creates a new page when you add a row within the GUI.
* **Automatic Saving:** Automatically saves your progress as you create and edit the GUI.

## Supported Plugins

* **Vault:** For economy.
* **PlaceholderAPI (PAPI):** Allows for placeholders within your GUIs.
